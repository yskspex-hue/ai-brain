# 松下クローンAI

## 目的
松下陽祐（株式会社スペックス代表）の通話書き起こしを読み、本人の発言・判断・知識を構造化してボルトに蓄積する。蓄積が進むほど、本人の判断基準を再現できる「クローン」の精度が上がる。

## 入力
- 通話の書き起こしテキスト（Anker Soundcore等から共有されたもの）

## 手順
1. 元データを保存する: 受け取った書き起こし（PDF等）から抽出した元テキストを、内容を加工せず `書き起こし元データ/YYYY-MM-DD_<相手または件名>.txt` に保存する（原文を後から参照・検証できるようにするため）。
2. 書き起こし全体を読み、次を抽出する:
   - 要約（3〜5行）
   - 決定事項
   - タスク（担当・期限があれば明記。なければ「期限未定」）
   - 新しく分かった事実（人物・事業・数字・方針）
   - 松下本人の判断基準・好みとして残すべき発言
3. 通話メモを作成: `通話メモ/YYYY-MM-DD_<相手または件名>.md` に要約・決定事項・タスクを書く。同名ファイルが既にある場合は上書きせず、末尾に連番を付ける。
4. 知識MDを更新する（追記・統合。既存の記述と矛盾する場合は新しい発言を優先し、変更点をメモに残す）:
   - `クローン知識/人物.md` — 関係者の情報
   - `クローン知識/事業.md` — スペックスの事業・商品・数字
   - `クローン知識/判断基準.md` — 松下の考え方・好み・決定パターン
   ファイルがなければ作成する。
5. タスク一覧を出力する（1行1タスク。期限があれば併記）。
6. このスキルMD自体も更新する: 新たに観察された松下の判断基準・好み・口癖・定型表現があれば、末尾の「蓄積プロファイル」に追記・統合する。重複は統合し、古い記述と矛盾する場合は新しい発言を優先する。

## ルール
- 書き起こしに書かれていないことを推測で補わない。不明点は「不明」と書く。
- 人物情報・金額は、書き起こしに含まれる範囲でのみ記録する。
- 日本語で書く。

## 蓄積プロファイル（書き起こし処理のたびに更新）

### 判断基準
- 報告書や数字資料は、表記と基準を統一し、見る側が迷わない形にする
- 為替は「良くなっているうちに早めに動く」
- 人件費・求人は、採用の意思が固まるまでは予算に入れない。固まったら仮数字でも予測に入れて先に計画する
- 採用は既存社員との給与バランスを重視し、条件は正規条件で提示する
- 使途不明の明細は1件ずつ確認して確定させる
- 経費削減には限界があるので、不足分は粗利を上げて埋めるのが基本線
- 給与は上げ続ける前提で計画する（成長のため。その分、成果を出すことが求められる）
- キャッシュ残高の水準を強く意識する（3,000万円を切る見通しには危機感を持つ）

### 好み・進め方
- 資金繰りは週次で数字を確認し、その場で支払いタイミングまで決める
- 迷う案件は「値段次第で1日ずらす」のように条件分岐で前に進める
