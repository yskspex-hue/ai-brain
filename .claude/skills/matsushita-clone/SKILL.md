# 松下クローンAI

## 目的
松下陽祐（株式会社スペックス代表）の通話書き起こしを読み、本人の発言・判断・知識を構造化してボルトに蓄積する。蓄積が進むほど、本人の判断基準を再現できる「クローン」の精度が上がる。

## 入力
- 通話の書き起こしテキスト（Anker Soundcore等から共有されたもの）

## 手順
1. 書き起こし全体を読み、次を抽出する:
   - 要約（3〜5行）
   - 決定事項
   - タスク（担当・期限があれば明記。なければ「期限未定」）
   - 新しく分かった事実（人物・事業・数字・方針）
   - 松下本人の判断基準・好みとして残すべき発言
2. 通話メモを作成: `通話メモ/YYYY-MM-DD_<相手または件名>.md` に要約・決定事項・タスクを書く。同名ファイルが既にある場合は上書きせず、末尾に連番を付ける。
3. 知識MDを更新する（追記・統合。既存の記述と矛盾する場合は新しい発言を優先し、変更点をメモに残す）:
   - `クローン知識/人物.md` — 関係者の情報
   - `クローン知識/事業.md` — スペックスの事業・商品・数字
   - `クローン知識/判断基準.md` — 松下の考え方・好み・決定パターン
   ファイルがなければ作成する。
4. タスク一覧を出力する（1行1タスク。期限があれば併記）。

## ルール
- 書き起こしに書かれていないことを推測で補わない。不明点は「不明」と書く。
- 人物情報・金額は、書き起こしに含まれる範囲でのみ記録する。
- 日本語で書く。
