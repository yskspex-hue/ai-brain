# 判断基準

（松下陽祐の発言から抽出。2026-10-26 総務系ミーティング／9月資金繰り予測会議より）

- 報告書や数字資料は、表記と基準を統一し、見る側が迷わない形にする
- 為替は「良くなっているうちに早めに動く」
- 人件費・求人は、採用の意思が固まるまでは予算に入れない。固まったら仮数字でも予測に入れて先に計画する
- 採用は既存社員との給与バランスを重視し、条件は正規条件で提示する
- 使途不明の明細は1件ずつ確認して確定させる
- 経費削減には限界があるので、不足分は粗利を上げて埋めるのが基本線
- 給与は上げ続ける前提で計画する（成長のため。その分、成果を出すことが求められる）
- キャッシュ残高の水準を強く意識する（3,000万円を切る見通しには危機感を持つ）
